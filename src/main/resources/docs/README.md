# 这个目录是干嘛的

这里是 **RAG 的语料目录**。`RagLoader` 启动时会扫描本目录下所有 `*.md`，
按标题切块、向量化、塞进 `SimpleVectorStore`，`/rag/search` 与 `/rag/ask`
检索的就是这些内容。

目前本地有 3 篇（Task10 用的语料）：

| 文件 | 大小 |
| --- | --- |
| `学习笔记-Task6-全局异常处理.md` | 约 27 KB |
| `学习笔记-Task8-业务异常重构.md` | 约 39 KB |
| `学习笔记-Task9-AI接入.md` | 约 29 KB |

合计切出 **138 块**（32 / 54 / 52）。

---

## 为什么 GitHub 上看不到这 3 篇

`.gitignore` 里有一条：

```
学习笔记-*.md
```

这条规则是**故意**的 —— 仓库是公开的，学习笔记里含个人信息和私人整理，
只留本地，不进版本库。所以本目录在仓库里**只有这个 README**。

> 也就是说：**clone 下来后 `/rag/ask` 一定答不出东西，这不是代码坏了。**

---

## clone 之后想跑通怎么办

1. 把任意 Markdown 笔记放进本目录（文件名随意，必须是 `.md`）；
2. 重启应用，看控制台有没有打印
   `学习笔记-xxx.md → N 块` —— 有就说明进语料了；
3. 调 `GET /rag/search?q=...&topK=5` 看 `content` 字段有没有命中。

没有语料时：`docs` 注入到的是**空数组**，`for` 循环一次都不进，
`vectorStore.add(...)` 加了个空列表 —— 启动照样成功，但检索结果必然为空，
`/rag/ask` 会统一回一句「笔记里没有相关内容」。

---

## 注意

- `README.md` 本身会被 `RagLoader` **跳过**（代码里有 `startsWith("README")` 判断），
  免得这份说明被当成语料混进检索结果。
- 本目录的文件只影响**启动时**的入库。改完笔记要**重启**才生效，
  因为向量是每次启动在内存里现算的（`SimpleVectorStore` 不做持久化）。
